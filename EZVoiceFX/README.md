# EZ Voice FX

VST3-плагин для Windows, который за один проход делает сырую вокальную дорожку чистой и одинаковой по громкости. Ставится первым в цепочку, до автотюна, компрессора и реверба.

## Цепочка обработки

| # | Модуль | Что делает | Крутилка |
|---|--------|-----------|----------|
| 1 | **Low Cut** | Срезает гул, вибрации стойки, низкий шум (24 дБ/окт) | Частота среза, 20–300 Гц (по умолчанию 80) |
| 2 | **De-click** | Убирает чмоки, щелчки рта, цифровые тики. Восстанавливает звук AR-моделью | Чувствительность, % |
| 3 | **Denoise (AI)** | Нейросеть **RNNoise** убирает фоновый шум. Работает локально, без интернета, весь CPU-бюджет ≈1–2% | Сила, % |
| 4 | **De-plosive** | Гасит удары воздуха на «П», «Б» | Сила, % |
| 5 | **De-reverb** | Подавляет хвосты отзвука комнаты (спектральный метод Lebart) | Сила, % |
| 6 | **Breath** | Делает вдохи между фразами тише (до −20 дБ) | Глубина, % |
| 7 | **De-ess** | Приглушает резкие «С», «Ш», «Щ» (только полосу выше 5,5 кГц) | Сила, % |
| 8 | **Auto-Level** | Выводит каждую капу на одну громкость (по умолчанию **−18 LUFS**) | Целевая громкость, LUFS |
| 9 | **Limiter** | Лимитер с упреждением, пики не превышают потолок | Потолок, дБ (по умолчанию −1) |
| – | **Output** | Общая громкость (стоит перед лимитером) | ±12 дБ |

У каждого модуля есть кнопка вкл/выкл. Двойной клик по крутилке возвращает значение по умолчанию. Кнопка **BYPASS** нужна для сравнения с исходником, задержка при этом учитывается.

## Как получить готовый плагин (автосборка на GitHub)

Ничего устанавливать не нужно, GitHub соберёт плагин сам.

1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Справа вверху нажмите **+ → New repository**. Название, например, `ez-voice-fx`, тип **Private** или **Public**. Нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**. Перетащите в окно **всё содержимое** папки `EZVoiceFX`, включая папку `.github`, и нажмите **Commit changes**.
   - Если папка `.github` не загрузилась (её не видно в списке файлов), зайдите во вкладку **Actions**, выберите **set up a workflow yourself**, вставьте текст из файла `.github/workflows/build.yml` и нажмите **Commit**.
4. Откройте вкладку **Actions**. Сборка **Build EZ Voice FX** запустится сама и займёт 10–20 минут. Когда появится зелёная галочка, нажмите на сборку и скачайте архив **EZ-Voice-FX-Windows-VST3** внизу, в блоке **Artifacts**.
5. Распакуйте архив. Папку **`EZ Voice FX.vst3`** скопируйте в `C:\Program Files\Common Files\VST3\`.
6. Пересканируйте плагины в DAW. Плагин находится в категории **EZVibe → EZ Voice FX**.

В архиве также лежит **`EZ Voice FX.exe`**: это отдельная программа, в которой плагин можно проверить без DAW (через микрофон).

Чтобы пересобрать плагин после изменений, загрузите новые файлы в репозиторий. Можно также зайти в **Actions → Build EZ Voice FX → Run workflow**.

## Как пользоваться

1. Поставьте **EZ Voice FX первым** на вокальную дорожку.
2. Включите в DAW **компенсацию задержки** (Plugin Delay Compensation). Обычно она включена по умолчанию. Задержка плагина около 47 мс, поэтому он для сведения, а не для мониторинга во время записи.
3. Настройки по умолчанию уже подходят для большинства кап. Если шум остался, поднимите **Denoise**. Если голос стал «металлическим», опустите его до 50–70%.

### Одинаковая громкость всех кап

- **Ride (auto)**: громкость выравнивается автоматически в реальном времени (окно около 3 с, в паузах усиление не меняется). Разброс между капами получается примерно ±1 дБ.
- **Learn (exact)**: точный режим.
  1. Нажмите **АНАЛИЗ (LEARN)**.
  2. Проиграйте капу целиком.
  3. Нажмите **СТОП И ПРИМЕНИТЬ**.

  Плагин измерит интегральную громкость по стандарту EBU R128 и выставит одно точное усиление. После изменения других крутилок замер стоит повторить. Значение замера сохраняется в проекте.

Для одинакового результата сохраните пресет DAW с вашими настройками и ставьте его на каждую капу.

### Советы

- **De-reverb** выше 60% может звучать неестественно. Для сухой будки хватит 0–20%.
- **De-click** выше 70% начинает трогать согласные. 30–50% подходит почти всегда.
- **Breath** с силой 30% делает вдохи тише примерно на 6 дБ.
- Лучшее качество нейросети получается при частоте проекта **48 кГц**. На 44,1/96 кГц плагин тоже работает, звук пересэмплируется внутри.

## Технические детали

- Формат: VST3 (Windows x64), плюс отдельная программа Standalone. Моно и стерео.
- Основа: JUCE 8.0.4, C++17.
- Нейросеть: RNNoise (Xiph.Org, лицензия BSD), модель встроена в плагин, файлы рядом не нужны.
- Громкость: K-взвешивание ITU-R BS.1770, гейтинг EBU R128.
- Все модули работают всегда (выключенный модуль просто не обрабатывает звук), поэтому задержка постоянная и в DAW ничего не «съезжает».

## Структура проекта

```

.github/workflows/build.yml    автосборка на GitHub
Source/PluginProcessor.*       параметры и цепочка обработки
Source/PluginEditor.*          интерфейс
Source/EZLookAndFeel.h         дизайн (крутилки, кнопки, цвета)
Source/dsp/*.h                 алгоритмы обработки
```

## Лицензии

JUCE распространяется под AGPLv3 или по коммерческой лицензии. Для личного использования плагина этого достаточно. Если захотите продавать EZ Voice FX, понадобится коммерческая лицензия JUCE. RNNoise распространяется под лицензией BSD.
