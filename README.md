# EZ Voice FX 1.1

VST3-плагин для Windows: за один проход делает сырую вокальную дорожку чистой и одинаковой по громкости. Ставится первым в цепочку, до автотюна, компрессора и реверба.

## Что нового в 1.1

- **Две нейросети шумоподавления.**
  - **AI Pro** (DeepFilterNet3) даёт лучшее качество на пении, крутилка задаёт глубину подавления.
  - **AI Lite** (RNNoise) почти не нагружает процессор.

  Переключаются на вкладке Advanced. Задержка при переключении не меняется.
- **Новые модули:**
  - **Hum 50/60**: убирает сетевой гул и его гармоники, частоту определяет сам.
  - **Gate**: приглушает паузы, открывается по нейро-детектору голоса.
- **Улучшенные модули:**
  - **De-plosive**: заглядывает вперёд на 2 мс и ловит начало удара.
  - **De-ess**: частота настраивается.
  - **De-reverb**: настраивается размер комнаты.
  - **Breath**: вдохи определяются с помощью нейросети.
- **True-peak лимитер**: ловит межсэмпловые пики с 8-кратной точностью.
- **Ассистент**: во время замера Learn плагин анализирует капу и сам выставляет Denoise, Gate, De-ess, De-plosive и Hum.
- **Learn по Play/Stop**: замер начинается и заканчивается вместе с воспроизведением в DAW.
- **Режим «Слушать удалённое»** (кнопка с наушниками): слышно, что именно вырезает плагин.
- **Bypass с выравниванием громкости**: можно честно сравнить с исходником.
- **Mix**: смесь обработанного и исходного звука, без фазовых проблем.
- **Пресеты**: 9 заводских плюс сохранение своих (в `Документы\EZ Voice FX\Presets`).
- **Undo / Redo.**
- **Новый дизайн** с **6 темами**: Neon Violet, Gold Luxe, Frost Light, Midnight Studio, Cyber Cyan, Black Gold. Тема переключается через шестерёнку.
- **Масштаб окна** 75–200%: через шестерёнку или растягиванием за угол.
- **Спектр до/после** с отметками частот модулей, **график громкости** за 30 секунд, индикатор нагрузки на процессор.
- **Сборка:** проверка плагина через pluginval и установщик `.exe`.

## Вкладки

| Вкладка | Что там |
|---|---|
| **Main** | AI Denoise, De-Esser, De-Reverb, Auto-Level, Limiter |
| **Clean** | Low Cut, Hum, De-Click, De-Plosive, Gate, Breath |
| **Level** | целевая громкость, режим Ride/Learn, кнопка анализа, Ассистент, график громкости |
| **Advanced** | выбор нейросети, частота де-эссера, размер комнаты, стерео в моно, режим прослушивания, задержка и нагрузка |

Внизу окна находятся Mix, Output, кнопка «слушать удалённое» и кнопка питания (Bypass).

## Цепочка обработки

Mono (опция) → Low Cut → Hum → De-click → AI Denoise → De-plosive → De-reverb → Gate → Breath → De-ess → Auto-Level → Output → True-peak Limiter → Mix

## Как собрать (GitHub)

1. Загрузите содержимое папки в репозиторий. Если файлы прошлой версии уже там, замените их.
2. Папку `.github` сайт GitHub не загружает. Создайте файл вручную: **Add file → Create new file**, имя `.github/workflows/build.yml`, текст скопируйте из файла `.github/workflows/build.yml` этого архива. Если такой файл уже есть, откройте его и замените текст целиком.
3. Через 20–35 минут во вкладке **Actions** появится зелёная галочка. Первая сборка дольше обычного, потому что собирается нейросеть AI Pro.
4. Скачайте архив **EZ-Voice-FX-1.1-Windows** из блока **Artifacts** внизу страницы сборки.

В архиве лежат:
- **`EZ-Voice-FX-1.1-Setup.exe`**: установщик, сам кладёт плагин в `C:\Program Files\Common Files\VST3`;
- папка `EZ Voice FX.vst3`: для ручной установки (копируйте папку целиком);
- `Standalone\EZ Voice FX.exe`: плагин как отдельная программа.

Если нейросеть AI Pro по какой-то причине не собралась, плагин всё равно соберётся и будет работать на AI Lite. В логе сборки при этом появится предупреждение.

## Советы

- Для лучшего качества AI Pro ставьте проект на 48 кГц.
- Задержка плагина около 80 мс. DAW компенсирует её автоматически, но для мониторинга во время записи плагин не подходит.
- Если вокал кажется «подводным», опустите AI Denoise до 50–70% или выключите Gate.
- Чтобы все капы были одинаковыми:
  1. Включите Level → Learn, Ассистент и «Замер по Play/Stop».
  2. Проиграйте капу целиком.
  3. Сохраните результат как свой пресет.
